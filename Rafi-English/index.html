Key features

Modular xPAK expansion
Two expansion areas with more than 20 combinations: add a thermal camera, barcode scanner, serial port or extra USB without tools.
2-in-1 tablet and laptop
Use the TOUGHBOOK G2 as a fully rugged tablet or add the optional detachable keyboard for a complete laptop experience.
Touchscreen for gloves, pen and rain
10.1-inch WUXGA IPS display with 1000 nits brightness and support for glove touch, digitizer pen and rain mode.
Intel vPro remote management
Intel AMT enables remote management and device recovery through vPro technology, even when the operating system is unresponsive.
Quick-release SSD
The SSD is quick and easy to remove for secure data handling and simple field maintenance.
Integrated security suite
TPM 2.0, infrared webcam for Windows Hello, smart card slot and optional NFC, all built into one rugged enclosure.
